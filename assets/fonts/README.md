# Brand fonts for designs

Weights 400 and 700 (latin) of the 20 fonts offered in brand kits, from Fontsource (`@fontsource/<name>@5`, WOFF).
All are Google Fonts under the SIL Open Font License 1.1 (Roboto: Apache 2.0), which allows bundling and use in images.
Bebas Neue and Anton have only one weight. Read by `src/lib/design-render.tsx`; nothing is loaded from Google at runtime.
